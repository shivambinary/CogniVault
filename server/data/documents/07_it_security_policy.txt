INTELLICORP TECHNOLOGIES
IT SECURITY POLICY
Document ID: IT-SEC-007 | Version: 1.0 | Effective date: 01 January 2026
Department: Information Technology

1. Account security
Employees must use individual accounts and must not share passwords. Multi-factor authentication must be enabled wherever the company provides it.

2. Passwords
Passwords must be unique and sufficiently strong. Employees must change a password promptly if they suspect it has been exposed. IT may require password changes after a security incident or system change.

3. Devices
Company devices must use approved security updates and endpoint protection. Devices should be locked when unattended. Lost or stolen devices must be reported to IT immediately.

4. Data handling
Company confidential information must be stored only in approved company systems. Employees must not upload confidential files to personal cloud storage or unapproved AI services.

5. Phishing
Employees should not open suspicious attachments or enter credentials after following an unexpected link. Suspected phishing messages should be reported to security@intellicorp.example.

6. Incident reporting
Report suspected account compromise, malware, data loss, or unauthorized access to security@intellicorp.example immediately.

7. Software
Only approved software may be installed on company devices. Requests for additional software should be submitted to IT.
