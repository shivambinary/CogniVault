Cognivault is an AI-powered enterprise search engine for finding information across company policies, manuals, FAQs, and technical documents. Unlike keyword search, it uses semantic retrieval to identify passages related to a question even when different words are used. Documents are extracted, split into chunks, converted into embeddings, and indexed. When users ask a question, the system retrieves relevant passages and uses Retrieval-Augmented Generation (RAG) to create a concise answer with source references. A web interface will support document upload, natural-language search, and ranked results. The prototype will be evaluated for relevance, answer grounding, and usability.
